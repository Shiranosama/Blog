## 知识管理

- **[Anytype](https://github.com/anyproto/anytype-ts)**
  - 基于对象的笔记/知识库工具

- **[logseq](https://github.com/logseq/logseq)**
  - 知识库笔记
  - 使用链接与标签关联知识
  - 隐私警告⚠️：默认不进行本地数据加密，所有条目均为明文
  - 版本分叉警告⚠️：目前分为数据库和纯文件两个版本

- **[Joplin](https://github.com/laurent22/joplin)**
  - 笔记编写/管理工具
  - 隐私警告⚠️：默认不进行本地数据加密，所有条目均为明文数据库

- **[hister](https://github.com/asciimoo/hister)**
  - 构建你的历史记录索引
  - 支持GET/POST/MCP API

- **[Calibre](https://calibre-ebook.com/)**
  - 开源Ebook管理工具
